# Parcours Maestro (simulateur iOS, build Release)

Build : `cd apps/mobile && npx expo run:ios --configuration Release --no-bundler`.
Identifiants du compte démo : jamais dans un fichier, passés à l'exécution.

    maestro test -e EMAIL=… -e PASSWORD=… .maestro/login.yaml

Les captures vont dans `.maestro/out/` (ignoré par git).
